Säkerhet

Från PR till Stable – en transparent kedja

Pipeline (kort)

  1. 1️⃣Inskick av recept + SBOM
  2. 2️⃣CI: SAST, licenskoll, CVE‑scan, virusscan
  3. 3️⃣Karantän 7–14 dagar & community‑review
  4. 4️⃣Manuell diff för kritiska paket
  5. 5️⃣Reproducible re‑build ×2 och signering
  6. 6️⃣Promotion till Stable

Exempel: verifiering

$ lpkg verify libphone-1.0.0.arm64.pkg
✔ signature: VALID (tuf: root@2025‑09‑01)
✔ sha256:    2f6b…a9e1
✔ builder:   reproducible (2/2 match)

Allt i Stable är signerat och kan verifieras lokalt.

Dokumentation

Kom igång

Snabbstart (flash)

$ fastboot devices
$ fastboot flash boot librephone-boot.img
$ fastboot flash system librephone-system.img
$ fastboot reboot

Se modellens sida för exakta partitioner och instruktioner.

Bygg från källkod

$ git clone https://example.org/librephone
$ cd librephone
$ make device=your_model release=stable
$ out/your_model/librephone.img
